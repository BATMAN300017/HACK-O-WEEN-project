## 6. Root Cause of the Blank Dashboard on Render

1. **IPv6-Only Supabase Direct Hostname:**
   - The direct connection string in `DATABASE_URL` uses `db.dyipyfvbqoqbjwcqlrqy.supabase.co:5432`.
   - `db.dyipyfvbqoqbjwcqlrqy.supabase.co` resolves exclusively to an **IPv6 address** (`2406:da14:1772:ea00:3711:e16c:bfce:57a4`) in AWS Tokyo.
   - Render's deployment environment provides **IPv4 egress only**. When the container attempts to resolve or connect to the IPv6 address on port 5432, the connection times out or fails with DNS error.
2. **Silent Fallback to Empty Local SQLite:**
   - `backend/app/core/database.py` contained a try/except block:
     ```python
     except Exception as e:
         logger.error(f"PostgreSQL connection error: {e}. Falling back to SQLite.")
     ```
   - When the IPv6 direct connection failed on Render, the backend fell back to SQLite (`sentinelflow.db`) inside the ephemeral container filesystem.
   - Because production auto-seeding was removed to protect real data, the container's local SQLite database was blank (0 transactions).
   - The dashboard loaded dynamic placeholders, but queries returned 0 records because it was querying the blank local SQLite database rather than Supabase.
