SentinelFlow AI — Visual Guide & UI Screenshots Tour
Key UI Screens & Walkthrough
1. Financial Investigation Command Center (/app or /)
Metric Cards: Transaction processing rate, alert generation counter, active case count, and verified false-positive rate.
Risk Calibration Grid: Breakdown across Routine (0-24), Low (25-49), Elevated (50-74), and High Priority (75-100).
Scenario Quick Launch: 1-click execution for Rapid Flow, Mule Network, and Benign Burst.
2. Live Transaction Stream (/app#transactions)
Searchable and sortable real-time transaction ledger.
Filterable by risk tier, amount, channel, and source account.
Dynamic color-coded risk indicators.
3. Priority Alert Queue (/app#alerts)
Aggregated detection findings from all 4 detection engines.
Direct 1-click conversion to an active investigation case.
4. Investigation Case Workbench (/app#case-detail)
Dossier Header: Case number, priority, status, evidence completeness score, and printable PDF export button.
Evidence Panel: Typed evidentiary records (Transaction, Behavioral Anomaly, Rule Match, Relationship, Contradictory factors) with SHA-256 integrity hash verification.
Investigative Checklist: Procedural playbook tasks with interactive checkboxes.
Sub-Graph Network: Radial interactive graph visualization mapping counterparties, accounts, and shared device clusters.
AI Investigation Copilot: Evidence-grounded natural-language query assistant with citation references.
5. Network Intelligence & Topology Explorer (/app#network)
Topological money-flow visualization.
Automatic detection of Fan-In Collection Hubs, Circular Round-Trip Transfers, and Rapid Multi-Hop Intermediary Forwarding.
6. Controlled Continuous Learning (/app#learning)
Active model telemetry and benchmark performance metrics.
Training data sample readiness tracker.
Promotion gate evaluation and candidate model management.
